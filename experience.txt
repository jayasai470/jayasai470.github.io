//stitcher-service
Architected a server-side, ad-supported linear "FAST channel" streaming platform for Samsung Smart TVs, assembling looping and scheduled playlists into continuous live streams.
Implemented server-side ad insertion (SSAI) via SCTE-35 markers, splicing ad breaks, slates, and bumpers directly into the live stream without client-side ad logic.
Designed a scheduling engine allowing fixed-time-window content blocks on an otherwise looping channel, with automatic filler coverage and publish-time overrun validation.
Built real-time EPG (Electronic Program Guide) generation with multi-language, multi-market program metadata kept in sync with live playlist state.
Enabled CMS for live, in-place channel editing content, overlays, and ad placements can be added, removed, or reordered on a running channel and republished without stream interruption.
Developed the backend in Node.js/NestJS on Kubernetes (EKS) with MySQL-backed playlist, channel, and content-asset persistence, delivering content via HLS through a CDN-backed origin.
Built a custom Kubernetes controller that reconciles published channels in the database with corresponding Kubernetes custom resources (CRDs), keeping cluster state automatically in sync.

Created the analytics pipeline using AWS Kinesis, S3, Glue, and Athena to capture, catalog, and query VAST tracking/engagement events, with QuickSight dashboards for playable-ad performance reporting.
Integrated the VAST ad service with stitcher-service's channel engine, supplying playable ad content for server-side ad breaks on live linear channels.
Developed the mini-game experiences as standalone, lightweight web apps optimized for Samsung TV-remote interaction.
Built the service on Node.js/NestJS, deployed on Kubernetes (EKS) via Helm, with CI/CD automation through GitLab.
